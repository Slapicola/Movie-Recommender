# Overview

To demonstrate the Java language, I wrote a software program the allows users to search up a movie from a database based on movie title, genre, and actors. The program also recommends movies to the user based on a favorite movie or a list of three movies that they have watched before.

I wrote this software to get a brief introduction to the Java language.

# Development Environment

To develop this software I used VSCode and a JDK.

I used the Java language and I used the Gson library for the JSON text I wrote with movie information.
